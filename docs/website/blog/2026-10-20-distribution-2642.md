### Distribution `2642` is now available

The [`2642.0`](https://github.com/IntersectMBO/mithril/releases/tag/2642.0) distribution has been released, introducing the following changes:

- **On-chain protocol configuration**: The Mithril signers and aggregators now read the protocol parameters and the signed entity types configuration from the Cardano chain (see this [post](https://mithril.network/doc/dev-blog/2026/10/20/on-chain-protocol-configuration))
- **Breaking Changes**: Removed support for `Gzip` compressed snapshot archives in the Mithril aggregator and client, and removed the deprecated `ClientBuilder::aggregator` constructor and `--cardano-network` option of the snapshot converter in the Mithril client library and CLI
- **Certificate chain cache**: The Mithril client library, CLI and WASM library can cache the verified certificate chain to speed up subsequent verifications (unstable, see this [post](https://mithril.network/doc/dev-blog/2026/10/20/certificate-chain-cache))
- **Cardano node**: Support for `Cardano node` `11.1.3` and preliminary support for the upcoming `Cardano node` `11.2`
- **DMQ node**: Support for the DMQ node `0.7.2.0` stable version
- **Maintenance**: Bug fixes and performance improvements.

This new distribution has been deployed to the **Mithril aggregator** on the `release-mainnet`, `release-preprod` and `pre-release-preview` networks.

For those running a **Mithril signer**:

- **pre-release-preview** network: upgrade the signer node binary to version `1.2.5` and set the new `PROTOCOL_CONFIGURATION_READER_ADAPTER_CONFIG` configuration parameter
- **release-preprod** network: upgrade the signer node binary to version `1.2.5` and set the new `PROTOCOL_CONFIGURATION_READER_ADAPTER_CONFIG` configuration parameter
- **release-mainnet** network: upgrade the signer node binary to version `1.2.5` and set the new `PROTOCOL_CONFIGURATION_READER_ADAPTER_CONFIG` configuration parameter.

:::info

There is a **grace period** for the new configuration parameter: signers without it keep working until the next distribution, which will remove the legacy fallback. Follow the [signer node documentation](https://mithril.network/doc/manual/operate/run-signer-node#set-up-the-service) to set it up.

:::

You can update the Mithril signer using the one-line command below. By default, it downloads to the current directory, but you can specify a custom folder with the -p option:

```bash
curl --proto '=https' --tlsv1.2 -sSf https://raw.githubusercontent.com/IntersectMBO/mithril/refs/heads/main/mithril-install.sh | sh -s -- -c mithril-signer -d 2642.0 -p "$(pwd)"
```
