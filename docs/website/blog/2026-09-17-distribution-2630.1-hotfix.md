### Distribution `2630.1` hotfix is now available

The [`2630.1-hotfix`](https://github.com/IntersectMBO/mithril/releases/tag/2630.1-hotfix) hotfix distribution has been released
to fix a crash of the Mithril aggregator and signer nodes when they read a Cardano block containing a deeply nested native script.

Since **September 16, 2026**, block `5183974` of the `preprod` network holds a transaction whose native script
is nested more than 5,000 levels deep. The Pallas library used by the Mithril nodes to decode blocks exhausted the stack
of the thread reading the chain, which aborted the nodes with a `stack overflow` error every time they resumed
the import of the Cardano transactions.

This distribution introduces the following change:

- **Bug fix**: Updated the Pallas library to version `1.3.0`, which decodes native scripts and Plutus data without recursion
  and prevents such crashes on all networks.

This new distribution has been deployed to the **Mithril aggregator** on the `release-mainnet`, `release-preprod` and `pre-release-preview` networks.

For those running a **Mithril signer**:

- **pre-release-preview** network: upgrade the signer node binary to version `1.1.9` (no configuration changes are required)
- **release-preprod** network: upgrade the signer node binary to version `1.1.9` (no configuration changes are required)
- **release-mainnet** network: upgrade the signer node binary to version `1.1.9` (no configuration changes are required).

:::warning

On the `release-preprod` network, signers running the `2630.0` distribution crash as soon as they reach block `5183974`
and stop signing: the upgrade to `2630.1` is **required** to resume signing.

:::

You can update the Mithril signer using the one-line command below. By default, it downloads to the current directory, but you can specify a custom folder with the -p option:

```bash
curl --proto '=https' --tlsv1.2 -sSf https://raw.githubusercontent.com/IntersectMBO/mithril/refs/heads/main/mithril-install.sh | sh -s -- -c mithril-signer -d 2630.1-hotfix -p "$(pwd)"
```
